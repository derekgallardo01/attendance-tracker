## Part 2: Priority 1–4 Ahrefs Lite Pull Checklist (Exact `Prefix` Mode Instructions)

Because Chrome Web Store (`chromewebstore.google.com`) and Google Workspace Marketplace (`workspace.google.com`) host thousands of unrelated extensions on the same root domain, **always set the Ahrefs Site Explorer target mode dropdown to `Prefix` (`URL prefix`)—never `Subdomains` or `Domain`**—when pulling marketplace listing backlinks.

### Priority 1: Abandoned / Delisted Chrome Web Store Attendance Extensions (`Prefix` Mode)
These legacy Chrome extensions are either completely delisted (HTTP 404 on the Chrome Web Store) or broken/unmaintained under Manifest V3. Every `.edu`, school district, and EdTech blog linking to these URLs is a high-conversion broken-link replacement target.

1. **Open Ahrefs Site Explorer** -> Set mode to **`Prefix`**.
2. Paste each URL prefix below -> Go to **Backlinks** (filter: **Dofollow**, **One link per domain**):
   - **Meet Attendance (Clay Codes — CWS Legacy URL)**:
     `https://chrome.google.com/webstore/detail/meet-attendance/nenibigflkdikhlmpkfbnlcfkbbkpnmn`
   - **Meet Attendance (Clay Codes — New CWS URL)**:
     `https://chromewebstore.google.com/detail/meet-attendance/nenibigflkdikhlmpkfbnlcfkbbkpnmn`
   - **Google Meet Attendance (Al Caughey — Broken/Deprecated)**:
     `https://chrome.google.com/webstore/detail/google-meet-attendance/fkdjflnaggakjamjkmimcbfefhppfljd`
   - **Attendance for Google Meet (Tyler & Adit — Unmaintained since 2023)**:
     `https://chrome.google.com/webstore/detail/attendance-for-google-mee/gioogehddfncebdepfoeimppbfhoghcp`
   - **MeetList Chrome Web Store Listing**:
     `https://chromewebstore.google.com/detail/google-meet-attendance-tr/appcnhiefcidclcdjeahgklghghihfok`
3. Export as **UTF-8 CSV** into `docs/ahrefs-exports/`.

### Priority 2: Tactiq's Specific Google Meet Attendance & Deleted Blog Subfolders (`Prefix` Mode)
Our earlier `tactiq.io` export capped at 2,500 rows across the entire domain. Using `Prefix` mode on Tactiq's Google Meet subfolders isolates the exact pages about Google Meet attendance and dead `/learn/` URLs without burning export rows on unrelated YouTube/Zoom pages:

1. **Open Ahrefs Site Explorer** -> Set mode to **`Prefix`**.
2. Run **Backlinks** & **Broken Backlinks** on:
   - `https://tactiq.io/learn/google-meet-attendance`
   - `https://tactiq.io/learn/` *(check the **Broken backlinks** tab in the left sidebar to surface all 404 `/learn/` articles at once)*
   - `https://help.tactiq.io/` *(check **Broken backlinks** tab to surface all dead localized help center links)*
   - `https://blog.tactiq.io/` *(dead Medium subdomain returning HTTP 403—export all referring domains)*
